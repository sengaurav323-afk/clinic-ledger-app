# Clinic Ledger — Patient Payments

A small, mobile-first web app for tracking patient payments at a clinic.

See SETUP-GUIDE.md for first-time setup instructions (Firebase project,
authentication, hosting).

## Features
- Sign in with email + password or mobile number (OTP)
- Each signed-in user's data is private to them
- Log a payment with one or more fee types (Counselling, Medicine, Referral, Other)
- Day / Week / Month views with totals
- "Who paid for what" breakdown by fee-type combination
- Mark as paid, delete entries, export to CSV
